# 开放性人格与语义记忆网络论文计算可复现项目

## 一、项目简介

本项目为论文 **《Remotely Close Associations: Openness to Experience and Semantic Memory Structure》（Christensen et al., 2018）** 的计算可复现研究。

本项目基于作者公开的数据，对论文中的主要分析流程进行了重复，包括：

* 开放性人格量表信度分析（Cronbach's α）
* 被试分组
* 语义流畅性数据处理
* 语义网络构建
* 网络指标计算
* 随机网络比较（Z-test）
* Bootstrap稳定性分析
* Cytoscape网络导出

由于原研究发表于2018年，近年来多个R软件包（SemNeT、SemNetCleaner、NetworkToolbox、igraph等）进行了较大的版本更新，原始代码无法直接运行。因此，本项目在保持原研究理论框架和分析思路一致的基础上，对部分实现方法进行了适配和修改，以保证能够在当前R环境下完成复现。

# 四、数据说明

项目包含以下数据：

**FINAL open.csv**

开放性人格量表原始数据，用于：

* Cronbach's α信度分析
* 开放性得分计算
* 高低开放性分组

**FINAL fluency.csv**

语义流畅性实验原始数据，用于语义网络构建。

此外，还提供：

**cleaned_data.RData**

该文件保存了已经完成：

* 拼写校正
* 词典校正
* 人工检查

之后的数据，可直接用于网络分析，无需重新进行人工校正。

# 五、如何快速复现

如果希望完整复现论文，请运行：

```
code/my_code_1.R
```

如果希望跳过人工校正步骤，可先执行：

```R
load("data/cleaned_data.RData")
```

随后从代码第八步（网络构建）开始运行即可完成主要分析。

# 七、说明

由于原论文所使用的软件包版本与当前版本差异较大，部分函数已经删除、更名或修改了返回对象结构，因此本项目对部分代码进行了调整，例如：

* 更新了网络构建函数的调用方式；
* 使用当前版本兼容的igraph函数；
* 调整了TMFG网络对象的读取方式；
* 根据新版软件包接口修改了部分统计分析流程。

所有修改均保持原论文分析逻辑一致，不改变研究问题及统计推断目标，仅解决由于软件版本更新导致的兼容性问题。
